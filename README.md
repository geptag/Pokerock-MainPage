Pokerock é um projeto fictício de Pokédex onde os Pokémons possuem a cabeça do “The Rock”. O projeto foi desenvolvido durante minha trilha de aprendizagem em programação na ONG Prototipando a Quebrada (PAQ), junto de outros 3 integrantes.

Este repositório contém apenas a minha versão do projeto.

---

° Sobre o projeto:
A ideia do Pokerock surgiu como um projeto divertido para praticar conceitos básicos de desenvolvimento web, consumo de API, organização de interface e lógica de programação.

O objetivo era criar uma Pokédex, misturando o universo Pokémon com o rosto do ator Dwayne Johnson "The Rock".

---

° Tecnologias utilizadas:

* HTML
* CSS
* JavaScript

---

° Funcionalidades

* Listagem de Pokémons
* Interface estilizada
* Alteração das imagens dos Pokémons para versões “Pokerock”
* Navegação simples e responsiva
